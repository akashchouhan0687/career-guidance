Learning Resources

Curated topics, technologies, and ideas to kickstart your learning journey.

Programming

Foundational software engineering.

What to Learn
  • Core Syntax & Logic
  • Object-Oriented Programming
  • Data Structures (Arrays, Trees)
  • Version Control (Git)
Suggested Technologies
  • Python, Java, or C++
  • GitHub / GitLab
  • VS Code Editor
Project Ideas
  • Command-line calculator
  • Personal task manager app

Web Development

Building for the internet.

What to Learn
  • Semantic HTML & Responsive CSS
  • JavaScript DOM Manipulation
  • API Fetching & Asynchronous JS
  • Basic Backend Routing
Suggested Technologies
  • HTML5, CSS3, Vanilla JS
  • React or Vue.js
  • Node.js / Express
Project Ideas
  • Personal portfolio website
  • Weather dashboard using public API

Cybersecurity

Protecting digital assets.

What to Learn
  • Networking Models (OSI/TCP)
  • Linux Command Line
  • Common Vulnerabilities (OWASP)
  • Cryptography Basics
Suggested Technologies
  • Kali Linux or Ubuntu
  • Wireshark (Packet Analysis)
  • Nmap (Network Scanning)
Project Ideas
  • Set up a secure home network
  • Complete basic CTF challenges

AI & Data

Analytics and machine learning.

What to Learn
  • Descriptive Statistics
  • Data Cleaning & Preprocessing
  • Database Querying
  • Supervised & Unsupervised ML
Suggested Technologies
  • Python (Pandas, Scikit-Learn)
  • SQL (PostgreSQL / MySQL)
  • Jupyter Notebooks
Project Ideas
  • Analyze a public Kaggle dataset
  • Build a movie recommendation system

UI/UX Design

Crafting digital experiences.

What to Learn
  • Design Thinking Process
  • Wireframing & Prototyping
  • Color Theory & Typography
  • Usability Testing
Suggested Technologies
  • Figma (Industry Standard)
  • Notion (For Research)
  • Basic HTML/CSS
Project Ideas
  • Redesign a local business website
  • Create a mobile app prototype

Professional Skills

Essential workplace abilities.

What to Learn
  • Effective Communication
  • Time Management
  • Agile/Scrum Methodologies
  • Resume Writing & Interviewing
Suggested Tools
  • Trello / Jira for Project Mgmt
  • LinkedIn for Networking
  • Google Workspace
Action Items

  • Do a mock interview with a peer
